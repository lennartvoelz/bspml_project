# Data Directory

This directory contains datasets used for algorithm development and validation.

## Structure

- `ppg_dalia/`  - PPG-DaLiA public dataset
- `real_world/` - Self-collected real-world data

## PPG-DaLiA Dataset

The PPG-DaLiA dataset should be downloaded and placed in the `ppg_dalia/` directory. 
This dataset contains PPG and accelerometer data collected during various activities.

## Real-world Data

The `real_world/` directory is for storing self-collected data for algorithm validation.
